# Code of conduct

Mahtem is a learning project. Everyone here is learning something.

- Be kind and patient, especially with beginners and with questions that seem basic.
- Criticise ideas and code, never people.
- No harassment, insults or discrimination of any kind.
- Assume good intent, and ask before assuming.

Maintainers may edit or remove contributions, and block participants, that break these expectations. To report a problem privately, contact the maintainer through GitHub.
